# 🔧 Ferretería Gonzales — Sitio Web

## Estructura de carpetas

```
ferreteria-gonzales/
├── index.html          ← Página principal
├── css/
│   └── style.css       ← Todos los estilos
├── js/
│   └── script.js       ← Lógica del carrito y navegación
├── img/
│   └── (aquí van tus imágenes locales si las tienes)
└── README.md
```

## Características

- ✅ **Inicio** — Hero animado, estadísticas, categorías, sección "por qué elegirnos"
- ✅ **Productos** — 12 productos con filtros por categoría, precios en Bs
- ✅ **Contacto** — Tarjetas de equipo, formulario de contacto
- ✅ **Carrito funcional** — Agregar, cambiar cantidad, quitar, finalizar compra
- ✅ **Diseño responsivo** — Adaptado a móvil y escritorio

## Uso

Abre `index.html` directamente en tu navegador. No requiere servidor.

## Precios en Bolivianos (Bs)

Todos los precios están expresados en bolivianos bolivianos (Bs).
